# kenja-no-hisho（賢者の秘書）

AI秘書「Muse」に、私生活の秘書の仕事をぜんぶ任せるための指示ファイル集です。
note「賢者の対策立案室」の記事と連動しています。

## 使い方

1. やらせたいことのファイルを選んでダウンロードします（このページの緑のボタン「Code → Download ZIP」で、全部まとめて落とすこともできます）
2. 落としたファイルを、自分のMuseに渡して「この通りにやって」と頼みます
3. ファイルの中ので囲んだ部分は、自分の情報（地域、時刻、予定の名前など）に書き換えてください

プログラミングは要りません。ファイルを渡して頼むだけです。

## 注意

- 指示ファイルは「型」です。時刻・地域・予定の名前などは、自分の生活に合わせて書き換えてください
- お金が動くこと、第三者への送信、削除など大事な操作は、AIに自動でやらせず、必ず自分の承認を挟む形にしてください（11の連携ルールに考え方を書いてあります）
